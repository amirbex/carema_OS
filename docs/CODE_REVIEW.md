### 🟡 کیفیت و نگهداشت

- تکرار کد «جمع‌آوری کانتکست برای AI» در سه جا → یک تابع `fetchWorkspaceContext`.
- تکرار منطق زیرتسک در دو کامپوننت → یک هوک مشترک.
- `any`‌های بی‌دلیل، ایمپورت‌های مرده، و کامپوننت `ErrorBoundary` نبود.
- نبود `@types/react-dom` (باعث `any` ضمنی در `main.tsx` و `Modal`).
- `package.json` با نام `react-example` و بدون اسکریپت تست/typecheck.
- نبود قفل نسخه (`package-lock.json`) و نبود `firebase.json` برای استقرار قوانین.
- آلودگی `alert()` در جریان استخراج فایل → Toast.
- نبود اعتبارسنجی ایمیل در اشتراک‌گذاری، نبود تأیید حذف وظیفه/فایل.

## ۳) ده پیشنهاد توسعه (به ترتیب اولویت)

1. **احراز هویت سمت سرور**: `firebase-admin` + ارسال ID Token در `Authorization`، اعتبارسنجی در `/api/ai/*` و `/live`، سهمیهٔ مصرف به‌ازای هر uid (جلوگیری از سوءاستفاده از کلید Gemini).
2. **پوشش تست خودکار**: Vitest + Testing Library برای کامپوننت‌ها، Playwright برای مسیرهای بحرانی (ورود → پروژه → وظیفه → چت → تأیید اکشن)، و تست قوانین Firestore با Emulator Suite.
3. **همکاری بلادرنگ واقعی**: حضور کاربران، کامنت زنده، و audit trail در Firestore (به‌جای تاریخچهٔ محلی) + مشاهدهٔ «چه کسی چه چیزی را تغییر داد».
4. **پیوست فایل حرفه‌ای**: آپلود مستقیم به Firebase Storage، استخراج متن PDF/DOCX سمت سرور، ویروس‌اسکن و chunk‌بندی برای RAG واقعی (به‌جای ذخیرهٔ متن در سند ۱MB).
5. **همگام‌سازی تقویم**: OAuth با Google Calendar/Microsoft 365، همگام دوطرفه و جلوگیری از تعارض رویدادها.
6. **جستجوی سراسری مقیاس‌پذیر**: ایندکس خارجی (Algolia/Typesense) روی پروژه/وظیفه/یادداشت + `Cmd+K` آنی، به‌همراه fuzzy matching.
7. **PWA و حالت آفلاین**: manifest + Service Worker، صف نوشتن آفلاین (Firestore persistence)، نوتیفیکیشن یادآور موعد وظایف.
8. **گزارش و تحلیل**: burndown، velocity، زمان صرف‌شده روی هر پروژه، خروجی PDF برندشده و ایمیل خلاصهٔ هفتگی.
9. **ارتقای لایهٔ AI**: Function-calling واقعی با schema (به‌جای JSON آزاد)، زنجیرهٔ چندمرحله‌ای، تأیید خودکار اقدامات کم‌ریسک، و حافظهٔ گفتگو در Firestore.
10. **زیرساخت و رصد**: Dockerfile، CI (`typecheck` + `test` + `build`)، Sentry، لاگ ساخت‌یافته، متریک مصرف/hزینهٔ Gemini و هشدار بودجه.
